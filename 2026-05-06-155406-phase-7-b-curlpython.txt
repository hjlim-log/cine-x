    endDate < startDate로 일괄 등록

    timeSlots: []로 일괄 등록

  2-8: 예매있는 상영 삭제 — 버그

  원인: Prisma P2003 FK constraint violation

  delete() 메서드의 count 쿼리가 status: { in: ['PENDING', 'PAID'] } 로만
  필터링하여, CANCELLED 상태 예매는 건너뜀. 그러나 CANCELLED 예매도 screeningId
  FK를 그대로 보유하고 있어 prisma.screening.delete() 호출 시 DB FK 제약
  위반으로 500 발생.

  수정 방법 (2줄):

  // admin-screenings.service.ts:184 — delete()
  const reservations = await this.prisma.reservation.count({
    where: { screeningId: id },  // ← status 필터 제거, 전체 카운트
  });

  이렇게 하면 CANCELLED 포함 모든 예매가 있으면 삭제 불가 → HTTP 400 정상 반환.
  MVP 범위상 이게 가장 단순한 fix.

  [수정 - 옵션 A: 진행 중 예매 차단 + CANCELLED cascade 정리]                   
                                                                                
  async delete(id: number) {                                                    
    return this.prisma.$transaction(async (tx) => {                             
      // 1. 진행 중 예매 검사 (PENDING/PAID)                                    
      const activeReservations = await tx.reservation.count({                   
        where: {                                                                
          screeningId: id,                                                      
          status: { in: ['PENDING', 'PAID'] },                                  
        },                                                                      
      });                                                                       
                                                                                
      if (activeReservations > 0) {                                             
        throw new BadRequestException(                                          
          `진행 중인 예매가 ${activeReservations}건 있어 삭제할 수 없습니다.`,  
        );                                                                      
      }                                                                         
                                                                                
      // 2. CANCELLED/EXPIRED/FAILED 예매 cascade 정리                          
      //    티켓 → 쿠폰/제휴할인 사용이력 → 예매 → 상영 순서                    
                                                                                
      const reservationIds = await tx.reservation.findMany({                    
        where: { screeningId: id },                                             
        select: { id: true },                                                   
      });                                                                       
      const ids = reservationIds.map(r => r.id);                                
                                                                                
      if (ids.length > 0) {                                                     
        // 쿠폰/제휴할인 사용 이력 정리                                         
        await tx.couponUsage.deleteMany({                                       
          where: { reservationId: { in: ids } },                                
        });                                                                     
        await tx.partnerDiscountUsage.deleteMany({                              
          where: { reservationId: { in: ids } },                                
        });                                                                     
        // 티켓 정리                                                            
        await tx.ticket.deleteMany({                                            
          where: { reservationId: { in: ids } },                                
        });                                                                     
        // 예매 정리                                                            
        await tx.reservation.deleteMany({                                       
          where: { screeningId: id },                                           
        });                                                                     
      }                                                                         
                                                                                
      // 3. screening 삭제                                                      
      return tx.screening.delete({ where: { id } });                            
    });                                                                         
  }
